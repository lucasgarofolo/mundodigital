# Imagens do Mundo // Digital

Esta pasta reserva as capturas da apresentação do projeto. Nenhuma imagem fictícia ou arquivo PNG/GIF vazio foi criado.

Adicione os arquivos abaixo e ative as linhas correspondentes nos comentários HTML do [README principal](../../README.md). Remova o comentário completo que envolve a imagem, mantendo apenas o Markdown ou HTML desejado. Na galeria, ajuste também os textos `alt` aos recortes escolhidos.

| Arquivo sugerido | Conteúdo |
| --- | --- |
| `hero.png` | Captura ampla do mapa com vários avatares circulando. |
| `checkin.png` | Captura ou revisão de selfie e aviso de processamento por IA. |

| `gallery-3.png` | Mapa, tracking ou admin com dados de demonstração. |

Prefira capturas reais da aplicação, com dados de demonstração e sem credenciais ou dados pessoais de visitantes. Hero e mundo funcionam bem em formato amplo; mantenha a galeria compacta. Só ative uma referência quando o arquivo correspondente existir.
